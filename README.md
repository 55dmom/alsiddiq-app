# مركز الصديق — تطبيق Android

تطبيق لإدارة مركز الصديق لتعليم القرآن الكريم: الحلقات، الطلاب، الحفظ والتسميع والمراجعة، الحضور، التقارير، المكافآت، والإعلانات — بأربعة أنواع حسابات (الإدارة، المعلم، الطالب، ولي الأمر).

- Kotlin + Jetpack Compose (Material 3)، عربي بالكامل RTL، الهوية من شعار المركز الأصلي.
- البنية: `ui/` الواجهات • `domain/` النماذج والصلاحيات والإحصائيات • `data/` واجهات المستودع وتطبيقاتها • `core/` بيانات المصحف (114 سورة، 604 صفحة، 30 جزءاً).
- قاعدة البيانات المركزية: Supabase (Postgres + Auth + Realtime) — المخطط وقواعد الأمان في `supabase/migrations/`.
- لا توجد أي مفاتيح سرية في الكود. عنوان الخادم والمفتاح العام يُمرَّران وقت البناء من متغيرات GitHub Actions.

## الحالة الحالية
هذه نسخة تجريبية: البيانات نموذجية ومحفوظة على الجهاز فقط (يظهر شريط «وضع تجريبي»)، ولا تتم المزامنة حتى يُربط مشروع Supabase.

## البناء
كل دفع إلى `main` يبني ملف APK على GitHub Actions، ويشغّل الاختبارات، ويلتقط صور الشاشات على محاكي Android، وينشرها في Releases.
